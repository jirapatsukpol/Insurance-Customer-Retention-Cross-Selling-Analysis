This project analyzes mock insurance datasets to create an interactive executive dashboard. It highlights key business metrics such as Total Premium and Loss Ratio, and specifically identifies target customers for cross-selling campaigns to drive revenue growth.

Tools Used:

Microsoft Excel: Data Cleaning, Validation, and Pivot Table Analysis

Power BI: Interactive Data Visualization and DAX Calculations

SQL: Data Extraction and Structuring (Concept)
